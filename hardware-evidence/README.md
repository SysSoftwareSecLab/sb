# Hardware-related evidence: scope

This folder currently contains finite offline support summaries only. The source project reused four frozen joint-command paths associated with OpenArm v1.0 and evaluated two fixed schedules: 1,249 serial and 673 simultaneous-start sampled instants (1,922 total), with no sampled surface intersections in the checked pairs. These are historical-command-based offline checks, not 1,922 new robot executions, continuous collision guarantees, or a validation of the generated benchmark programs on hardware.

Raw hardware recordings, robot meshes, and model packages are **not included** in this candidate. Their scientific linkage, anonymous metadata, redistribution permissions, and self-contained dependencies still need a separate release check before any hardware-reproduction claim is made. No hardware provenance is inferred from an illustrative rendering.

The known robot is OpenArm v1.0 bimanual, not v2.0. A foam fixture is 90 x 90 x 50 mm; the formal paperboard asset is 237 x 170 x 1 mm. Actual complete table measurements are unavailable. Standardized tables or posed renders must be labeled illustrations, not replicas of the measured workstation.
