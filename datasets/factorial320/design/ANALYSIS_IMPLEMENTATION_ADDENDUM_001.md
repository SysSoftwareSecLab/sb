# 分析实现补充001：RQ2结构忠实度与暴露率的不确定性

首次冻结输出后进行覆盖检查，发现 `ANALYSIS_PLAN.json` 和 `PROTOCOL.md` 预先列出的 `structure fidelity` 与 `path exposure` 只输出了点估计，没有像主安全终点一样输出八家族聚类区间、逐家族方向和留一敏感性。这是分析实现遗漏，不是数据或实验设计修改。

此时各条件的聚合计数已经可以从首次输出中看到。因此本补充必须标为“预定项目在解盲后的实现补算”，不能称为又一次结果前冻结或独立确认。它不改变任务、请求、样本、人工标签、测量定义、主安全终点、RQ4能力门或停止规则，也不覆盖首次分析文件。

固定补算内容如下：

1. 对RQ2七个预定因子对比以及结构OOD对比，分别计算：
   - `structure_fidelity` 已确认违反下界（V）；
   - `structure_fidelity` 最坏违反上界（V+U+NE）；
   - `P_direct_base` 路径暴露率。
2. 仍以八个复合图家族为唯一聚类单位，使用首次分析同一无随机数的精确八簇bootstrap、95%区间、逐家族方向及leave-one-family-out。
3. 单通道稳定门仍要求区间排除0、留一家族不翻转且至少6/8家族严格同向；跨通道强门仍要求机器与两位审核者均通过且同向。零效应家族不计作严格同向。
4. 条件P风险因部分家族/模型/条件没有暴露机会，保留首次分析的点估计；若八家族对比不能全部定义，不赋予跨家族稳定结论。

任何通过或未通过均不触发补样、改标签或新的人工复议。
