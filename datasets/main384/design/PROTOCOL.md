# Paper3 main study v1（2026-09-12）

本目录是 `MAINLINE_ADMISSION_2026-09-12.json` 约束下的第一项主线实证，不是工具开发或局部诊断。

## 论文主比较

- **RQ1 / 主表 T1**：384 个自然生成程序的程序级缺陷分布；分母始终包括无效输出和无法判定项。
- **RQ2 / 主表 T2**：4 个并发族和 4 个长程依赖族，各自在两个布局上做配对比较。每个配对块固定生成模型、prompt 和 repeat；动作多重集在结构对内相同。
- **RQ4 / 主表 T3**：同一任务、prompt、repeat 上 GLM-4.7 与 GLM-5 的自然错误迁移；独立能力题只用于验证“能力确有变化”，不按模型名称假定能力次序。
- **RQ3 / 主表 T4**：只在上述同一批自然程序和预先冻结的 controlled mutation 上运行现有方法；禁止再造独立 judge 小样本。

## 有限规模

64 个公开任务条件 × 3 个生成设置 × 2 个 prompt × 1 次预注册生成 = **384 个自然程序**。冻结前使用旧 360 得到：任一 U 的程序为 138/360（38.3%），程序级违规下界 92/360（25.6%）；按仅 5 个旧 parent 做的探索性 ICC 为下界 0.117、上界 0.481。正因为结构内相关明显，本轮把原拟重复调用改投到 **16 个任务族**，而不是用同一结构多抽一次。程序级人工复核按每人每程序 10 分钟估算为 64 小时；加 25% 争议/休息缓冲为每人 80 小时，低于两位复核者各 150 小时的既有承诺。不能据此宣称小效应功效充分：主结果报告配对风险差、任务族聚类区间与完整分母；细分结果若支持不足即保持描述性。

## 四类真正留出

1. **属性组合**：`D3/D4` 的“跨臂事件 + 容量锁 + 第二资源生命周期 + 有限循环 + 第二轮 readiness 分支”联合签名；匹配到 `D3` 的正确参考和 `C1/P01` 开发基线。只检验联合组合泛化，不作单属性因果归因。
2. **控制流**：`D4` 的 `for -> if -> asyncio.gather -> join -> transfer`；`D3` 是动作多重集相同的串行检查基线。
3. **布局**：`LH` 是改变路径交叉关系的新拓扑，不是坐标缩放或重命名；每个 `LH` 与同一任务结构的 `L0` 配对。只有确实包含两条运动路径的任务进入布局主效应分母。
4. **mutation family**：`MF-H1` 只在冻结后从 `D3/D4` 正确参考产生，第二次循环条件性遗漏第二资源释放；与逐字绑定的正确参考配对，与自然生成严格分开。

开发曝光按 `run_task` 实际可达调用图和 AST 嵌套关系计算，不以同文件关键词判定。所有 prepare/run/package 入口先核验硬准入文件和科学冻结哈希；不通过即停止，不回到旧的 16/18/12 样本或物理探针。

## 独立真值和停止规则

- 真值来源：冻结任务合同、受限运行器可信事件、现有任务/几何判据、以及两名互盲人工复核；模型 judge 不是 ground truth。
- 缺失/无效：生成无可解析入口、传输失败、执行不完整、几何不适用、人工争议分别计数，禁止从分母静默删除。
- 停止：384 个冻结自然槽只允许传输级恢复，不按输出质量补抽；结果为零或为阴性也停止。参考资格失败时只允许一次主设计修订，失败对象从对应主效应分母剔除并如实保留，不新增小探针。
