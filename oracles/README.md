# Independent evidence and historical implementations

Source snapshots cover structural checks, task requirements, the coherent-pair model, amended recomposition scoring, and finite geometry. Adjudication facts preserve the independently recalculated API and geometry facts supporting the final main384 endpoint.

These sources document what was measured; their original module and filesystem assumptions are not a portable installation. The supported offline path is `environment/revalidate.py`. No test-method prediction is substituted for reference truth. Finite Cartesian geometry and event reasoning are not full rigid-body dynamics, continuous collision certification, or hardware validation.

Historical paths retained inside snapshot code are provenance, not instructions to access other projects. Source-era checksums refer to original files, not necessarily anonymized export bytes.
